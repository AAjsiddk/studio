# **App Name**: Link Hub

## Core Features:

- Link Display: Display all provided links as buttons.
- Link Navigation: Clicking a button opens the corresponding link in a new tab.
- Copy Link: Each link has a button to copy the URL to the clipboard.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to suggest clarity and ease of use.
- Background color: Very light blue (#F0F8FF), almost white, with a hint of the primary hue.
- Accent color: Light orange (#FFB347), approximately 30 degrees to the 'left' of sky blue, for a contrasting but harmonious effect on interactive elements.
- Body and headline font: 'PT Sans' for a modern and clear presentation.
- Clean, card-based layout with ample spacing for readability.
- Simple, universally recognized icons for link actions (e.g., a globe for 'Visit', a clipboard for 'Copy').
